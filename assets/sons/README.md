# Sons de bicicleta (planejados)

O autor deseja um som de bicicleta ao ligar e ao desligar o RadioCiclista, feito para seu pai que trabalha com bicicletas. Ainda não há arquivos de áudio nem reprodução implementada.

Usar gravações próprias ou arquivos com licença compatível, com créditos e origem documentados. Não incorporar arquivos baixados sem licença conhecida.

O som de desligamento exige uma ação controlada por software antes de interromper a energia. Cortar a alimentação diretamente não deixa tempo para reproduzir áudio.
